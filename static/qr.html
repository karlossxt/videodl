Cómo hacer un código QR

  1. Elige el tipo y rellena los datos. La vista previa se actualiza sola.
  2. Ajusta el tamaño: 512 px para web, 1024 px o SVG para imprimir.
  3. Comprueba el contraste: negro sobre blanco es lo más seguro.
  4. Descarga y prueba el QR con la cámara de tu móvil antes de publicarlo.

PNG o SVG: cuál elegir

El PNG es una imagen de mapa de bits: cómodo para web, WhatsApp y redes sociales, pero se puede pixelar si lo amplías mucho. El SVG es vectorial: se imprime a cualquier tamaño sin perder nitidez. Para carteles, vinilos o imprenta, usa SVG o un PNG de 1024 px como mínimo.

Por qué el QR no se lee

Las causas más comunes son un contraste bajo, un contenido demasiado largo (más módulos y menos espacio entre ellos), imprimirlo muy pequeño o tapar los márgenes. Deja siempre el margen de 3–4 módulos, usa colores oscuros sobre fondo claro y prueba el resultado con dos móviles distintos antes de llevarlo a imprenta.

Privacidad y límites

El contenido se escribe en tu navegador y solo se envía al servidor para dibujar el QR. No se guarda, no se registra y no se comparte con terceros. El límite es de 1200 bytes (unos 1200 caracteres ASCII) para que el código siga siendo legible; una contraseña de WiFi o un enlace normal caben de sobra. El servidor no consulta el enlace ni accede a él.

Preguntas frecuentes

¿El código QR caduca?

No. Es una imagen estática con el contenido dentro: no depende de ningún servicio, así que funciona mientras el enlace o el dato sigan siendo válidos. Si cambias el contenido, tienes que generar y sustituir el QR.

¿Puedo cambiar el enlace sin cambiar el QR?

No con un QR estático. Para eso necesitas un enlace intermedio (un acortador propio) que puedas redirigir después. Esta herramienta genera QR estáticos, sin cuentas ni seguimiento.

¿Funciona con la cámara del iPhone y de Android?

Sí. Las cámaras actuales de iOS y Android leen QR de forma nativa. Si el QR es muy denso o tiene poco contraste, acerca la cámara y prueba con buena luz.

¿Puedo usar mis colores de marca?

Sí, siempre que los módulos sean más oscuros que el fondo y el contraste sea alto. La herramienta avisa y el servidor rechaza combinaciones que no se puedan escanear. Para máxima compatibilidad, blanco y negro.

¿Se guarda mi contraseña de WiFi?

No. La contraseña se usa para construir el contenido del QR y se descarta al devolver la imagen. Aun así, recuerda que cualquiera que vea el QR puede leer la contraseña: no lo publiques fuera del local.
