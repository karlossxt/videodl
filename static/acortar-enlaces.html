    ¿Cómo acortar un enlace?

    1. Pega la dirección larga en la caja de arriba.
    2. Pulsa «Acortar enlace».
    3. Copia el enlace corto y compártelo donde quieras.

    Preguntas frecuentes

    ¿Puedo ver a dónde lleva un enlace corto antes de abrirlo?

    Sí. Pega el enlace en «Comprueba un enlace corto antes de abrirlo» y verás la dirección de destino completa sin visitarla. Es una buena costumbre con cualquier enlace corto que no esperabas recibir.

    ¿Qué enlaces no se pueden acortar?

    Los que no empiezan por http o https, los que llevan usuario y contraseña, las direcciones IP y los nombres de redes internas, los enlaces de otros acortadores y los de este mismo sitio. Son límites pensados para evitar que el servicio se use para engañar a otras personas.

    ¿Cómo reporto un enlace malicioso?

    Pégalo en «Comprueba un enlace corto antes de abrirlo» y pulsa «Reportar este enlace». Cuando varias personas distintas lo reportan, el enlace se bloquea automáticamente.

    ¿Los enlaces caducan?

    Los enlaces que nadie visita durante un año se eliminan. Mientras se sigan usando, siguen funcionando.

    ¿Cuántos enlaces puedo crear?

    Hay un límite de enlaces nuevos por hora para evitar abusos. Si lo alcanzas, vuelve a intentarlo un rato después.

    ¿Qué se guarda de mi enlace?

    La dirección de destino, la fecha de creación y un contador de visitas. No hace falta cuenta y no se guarda tu dirección IP junto al enlace. Cualquiera que tenga el enlace corto puede ver a dónde lleva, así que no lo uses para enlaces privados.
